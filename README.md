# Talktunes-online-music-store

Talktunes is a JavaEE based online music store. You can simply register and log in with this system. Also, you can download music tracks and pay for this using the demo payment gateway. The payment gateway, not an actual one. It's we made demo gateway. This system contains two major parts.

 1. Customer Section
 2. Administration Section

Administration Section, the admin of the system can monitor and control the whole web application. These are the features included in the system.

 1. Add Music Track
 2. Update and Delete Musci Track
 3. View Payment Details
 4. View Feedbacks
 5. Summary of the Music store

## Technologies

 1. HTML
 2. CSS
 3. JavaScript
 4. JavaEE
 5. MySQL
